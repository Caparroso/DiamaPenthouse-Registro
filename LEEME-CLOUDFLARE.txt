LA MERECIDA BURGER - PUBLICACION SIN GITHUB

Sube directamente esta carpeta completa a Cloudflare Pages.

1. En Cloudflare abre Workers & Pages.
2. Elige Create application > Pages > Drag and drop.
3. Crea un proyecto llamado la-merecida y arrastra esta carpeta completa.
4. Comprueba primero la direccion temporal terminada en pages.dev.
5. En el proyecto abre Custom domains y agrega www.lamerecidaburger.com.
6. Solo cuando Cloudflare muestre el destino exacto, cambia en Squarespace el CNAME de www:
   - Valor anterior: lamerecida.github.io
   - Valor nuevo: el dominio terminado en pages.dev que indique Cloudflare.
7. En Squarespace configura una redireccion permanente 301 de @ hacia www.lamerecidaburger.com.

IMPORTANTE

- No borres los registros MX, SPF, DKIM ni otros registros de Google Workspace.
- No cambies los servidores de nombres para esta configuracion sencilla.
- Verifica la pagina temporal de Cloudflare antes de cambiar el DNS.
- Conserva GitHub como respaldo hasta confirmar que el dominio abre por HTTPS en datos moviles.

ACTUALIZACIONES FUTURAS

Para publicar una version nueva, abre el proyecto en Cloudflare Pages, elige Create deployment y vuelve a subir la carpeta actualizada.
